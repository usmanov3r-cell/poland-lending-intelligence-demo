# Release candidate scope and provenance

This independent portfolio export was built from the executive HTML snapshot and selected quantitative summaries of archived public calculator observations. It intentionally does not contain:

- API credentials, any `.env`, secrets or personal data
- private archive screenshots, page-text captures, evidence hashes or HTML captures
- the original development Git history or unrelated legacy Python scripts
- the paid-AI integration, live web capture modules or original lender monitoring databases

**Important:** A checksum of a bundled fixture or exported dashboard does not prove the external lender source is correct. It only detects unintended changes to the bundled bytes.

To publish a more complete public engine later, replace this export with a genuinely independent, fixture-driven build of the upstream capture/research architecture after reviewing licensing, provenance and sensitive-data exposure. Do not represent this snapshot pack as a full live AI market watcher.
